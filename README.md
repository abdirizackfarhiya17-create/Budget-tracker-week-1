# Week 1 Assignment: Personal Budget & Expense Tracker Skeleton

## Project Overview
This project establishes a responsive HTML structural layout and foundational CSS stylesheet for a client-side Personal Budget and Expense Tracker. It features a standalone control panel to handle inputs alongside a clear placeholder window designated for historical transaction lists.

## Structure and Architecture
* **`index.html`**: Contains semantic body elements partitioning the control card dashboard and output records.
* **`style.css`**: Manages alignment boundaries, responsive sizing cards, and color hierarchy variables.

## Implemented CSS Selectors Breakdown
The design system utilizes three specific selector types to format the project layout smoothly:
1. **Element Selectors (`body`, `h1`, `input`, `select`)**: Normalizes base styling parameters across standard semantic text rendering nodes and native form field nodes.
2. **ID Selectors (`#main-header`, `#add-expense-section`, `#expenses-display-section`)**: Applies highly precise structural rules and distinctive colored border accent banners across major section containers.
3. **Class Selectors (`.container`, `.content-box`, `.form-group`)**: Provides highly reusable layout grids to standardize padding distributions, boundary borders, and alignment offsets universally across individual blocks.
